🚀 Cara Deploy Aplikasi

1. Gabungkan semua blok (1–27) secara berurutan menjadi satu file index.html.
2. Pastikan Blok 10 menggunakan versi R1 yang sudah diperbaiki.
3. Buka file di browser (Chrome/Edge/Firefox) dan mulai gunakan.
4. Untuk deploy ke hosting (GitHub Pages, Netlify, Vercel), upload file index.html saja.
⚠️ Peringatan: Aplikasi ini menyimpan data di localStorage browser. Hapus data browser akan menghapus semua data toko. Gunakan fitur Backup secara berkala.
